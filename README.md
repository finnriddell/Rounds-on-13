# Rounds on Thirteen

Thirteen bells, ringing every possible order of themselves: 6,227,020,800 rows, each rung exactly once. It began at 00:00 UTC on 15 November 2026 and returns to its starting order around 28 June 2719.

The page works out which row is ringing from the clock, so it is always "playing", and everyone who opens it hears the same moment.

It is a single self-contained file, `index.html`, with no dependencies. Open it in a browser, or host it with GitHub Pages (Settings, Pages, deploy from the `main` branch).

## Where it comes from

English change ringing: bells rung in permutations, not tunes, under two rules. A bell may move only one place from one row to the next, and no row may ever repeat. This piece uses the oldest method, plain changes, stretched far past what any human band could ring.

The piece contains itself. Take every 13th row and set aside the fastest bell, and what is left is the same piece on twelve bells. Every 156th row gives eleven, and so on down. The ◂ ▸ lens in the page steps through those levels.
